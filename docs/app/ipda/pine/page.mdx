# Pine Script

The repository ships the full combined TradingView indicator as `ipda/file.txt`
(`IPDA + MS + OB + FVG + TrendLines`, short title `IPDA_Full`).

## Install on TradingView

1. Open TradingView → **Pine Editor**
2. Paste the contents of `file.txt`
3. **Add to chart**
4. Set the chart to **5M** and **Sensitivity** to **14** to match this service

Alert toggles live under the **Alert Settings** input group (IPDA Buy/Sell, TBO, BOS, OB zones,
FVG, IFVG, and more).

## What the Python service ports

Only **Section 5** — the IPDA Supertrend ▲/▼ labels — is executed by the signal service:

```
supertrend(close, sensitivity=14, atrLen=11)
sma = ta.sma(close, 13)
BUY  / SELL on crossover / crossunder with the SMA filter
```

`atrLen=11` and SMA length 13 are hardcoded in the Pine call. Only Sensitivity is a Pine
input. See [Signal Logic](/ipda/signal-logic).

## Visual-only on the chart

These sections remain on the chart for discretionary context and are **not** submitted as
orders by the Python service:

| Section | Content |
|---------|---------|
| Market Structure | BOS / ChoCH fractals |
| Session FVG | Daily session fair value gaps |
| Order Blocks | Bu-OB / Be-OB / BB / MSB |
| Trend Lines | Pivot-based trend lines |
| IFVG | Inversion fair value gaps |
| Smart Trail, SuperIchi, Range Filter, TBO | Overlay indicators |
| Reversal / S&R / Reversal Cloud / MACD candle color | Optional visuals |
