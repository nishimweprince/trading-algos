# Backtesting Service

**Backtesting Service** runs session-open strategy research, deterministic backtests, and the paper
loop on one closed-candle engine. It can stage or submit cTrader order payloads through
[Execution Service](/execution-service), but live order submission remains deliberately gated.

<Callout type="info">
  Paper and backtest fills use the next closed bar's open. This is not tick-level execution, and a
  validated UI backtest does not change the paper loop's environment configuration.
</Callout>
