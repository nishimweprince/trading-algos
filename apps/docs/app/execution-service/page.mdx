# Execution Service

**Execution Service** is the repository's unified FastAPI gateway for broker market data and
durable, idempotent trade execution. The active macOS production profile runs the cTrader adapter;
the same service also contains the Windows MT5 adapter.

<Callout type="info">
  The pre-migration `ctrader-markets` and `mt5-trader` documentation URLs redirect here. The
  top-level `mt5-trader/` service remains frozen for rollback and later retirement; no MT5
  multi-account behavior is implied by these docs.
</Callout>

## Capabilities

- Live ticks, closed candles, symbol metadata, and SSE tick streams.
- Explicit account targeting with demo/live execution gates.
- Durable operation and per-target state in SQLite.
- Idempotent replay, reconciliation, and fail-closed handling of ambiguous broker results.
- cTrader and MT5 adapters behind one HTTP contract.
