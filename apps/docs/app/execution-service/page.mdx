# Execution Service

**Execution Service** is the repository's unified FastAPI gateway for durable, idempotent trade
execution. Market data lives in [Market Data Service](/market-data-service). The active macOS production profile runs the cTrader adapter;
the same service also contains the Windows MT5 adapter.

<Callout type="info">
  The pre-migration `ctrader-markets` and `mt5-trader` documentation URLs redirect here. The
  former top-level services have been retired. MT5 remains single-account per process; use one
  named execution-service profile and one terminal session for each broker account.
</Callout>

## Capabilities

- Explicit account targeting with demo/live execution gates.
- Durable operation and per-target state in SQLite.
- Idempotent replay, reconciliation, and fail-closed handling of ambiguous broker results.
- cTrader and MT5 broker plugins behind one HTTP contract.
