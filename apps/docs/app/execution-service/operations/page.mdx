# Operations

macOS production runs under `com.execution-service.production` from the workspace console script,
with `services/execution-service/` as its working directory and `--profile production` as its
argument. The supported installer lives at `infra/launchd/install.sh`.

```bash
infra/launchd/install.sh production --check
launchctl print gui/$(id -u)/com.execution-service.production
curl -fsS http://127.0.0.1:8010/health/live
curl -fsS http://127.0.0.1:8010/health/trading-ready
```

The legacy `com.ctrader-markets.*` labels must remain unloaded while the unified service owns the
same port and OAuth token cache.

<Callout type="warning">
  Never run two processes against the same cTrader token cache or port. Stop the current token
  owner and confirm the listener is gone before invoking the preserved rollback unit.
</Callout>

## MetaTrader 5

The Windows host runs the same codebase with `ADAPTERS=mt5` instead of launchd. Its startup
checklist, logging surfaces, response handling, reconciliation, backup and key-rotation procedures
live in `services/execution-service/docs/mt5-operator-runbook.md`.

HFM and FTMO run as separate `--profile hfm` and `--profile ftmo` processes on ports `8000` and
`8001`. Each profile must point to its own terminal/account and owns distinct database and log
paths. Validate both configurations before starting either process; never use multiple workers for
one profile.
