# Configuration

The supported cTrader deployment uses `.env.production` plus
`data/accounts.production.toml`. Real environment variables override the profile file.

## Core settings

| Setting | Purpose |
|---|---|
| `ADAPTERS` | Select configured broker adapters, such as `ctrader` or `mt5` |
| `HOST`, `PORT` | HTTP bind address and port |
| `API_KEY` | Authentication for `/v1/*` routes |
| `DATABASE_PATH` | Durable idempotency and reconciliation ledger |
| `TRADING_ENABLED` | Global mutation gate; defaults off |
| `LIVE_TRADING_ENABLED` | Additional live-account gate; defaults off |
| `ALLOWED_SIGNAL_SOURCES` | Allowlisted upstream source names |

## cTrader settings

The profile supplies OAuth application credentials, token values or token-cache path, broker
environment settings, and configured symbols. The account registry assigns stable aliases and
optional canonical-to-broker symbol mappings. Startup fails closed when required enabled accounts or
symbols cannot be reconciled.

Do not reuse MT5 synthetic-index names for a cTrader broker: symbol names are broker-specific and
case-sensitive.

## MT5 compatibility

The unified adapter retains the existing MT5 HTTP and data contracts. Named HFM and FTMO profiles
load `.env.hfm` and `.env.ftmo`; their examples use separate ports, magic numbers, databases, and
logs so the two processes cannot share mutable state. Each process owns exactly one local MT5
terminal session.

Required MT5 fields are `MT5_TERMINAL_PATH`, `MT5_LOGIN`, `MT5_PASSWORD`, `MT5_SERVER`,
`ALLOWED_SYMBOLS` or `SYMBOLS_FILE`, and `MAXIMUM_VOLUME`. Terminal paths, server names, and symbols
are broker- and account-specific. Keep `TRADING_ENABLED=false` until `/health/trading-ready`, account identity,
symbol names, volume limits, and idempotent replay have been verified. Both supplied profiles send
notifications to `https://notifications.nishimweprince.dev` when configured with its API key. HFM
and FTMO select gold-only `symbols.hfm.json` and `symbols.ftmo.json` manifests; `mt5_symbol` values,
rather than the cTrader-only account registry, form the MT5 allowlist. Do not configure
`ALLOWED_SYMBOLS` at the same time as `SYMBOLS_FILE`.
