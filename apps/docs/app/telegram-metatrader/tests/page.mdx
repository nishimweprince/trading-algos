# Tests

From `telegram-metatrader/` with the venv activated and `pip install -e .[dev]`:

```powershell
pytest
```

`pyproject.toml` sets `testpaths = ["tests"]` and `asyncio_mode = "auto"`. The suite covers
parser, config, service, and MT5 executor behavior under `tests/`.
