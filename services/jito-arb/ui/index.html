Latency to land a candidate

Targets come from Jito's 50 ms auction tick: land in the first tick after a gap opens. Feed lag is when we receive an account update minus when Helius produced it (created_at), on synced clocks. Slot offset adds where in the ~200 ms slot the trade happened. Detect to signed covers everything we control before the HTTP write; Jito Frankfurt adds about 1 ms one way (1.9 ms RTT measured).
